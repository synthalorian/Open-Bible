# Asset credits

The files below replace bundled assets that were not images, or supply maps the app already referenced. Each one is a resized derivative of a Wikimedia Commons file whose public-domain status is recorded on that file page. Illustration JPEGs are at most 1400 pixels wide. Map PNGs are at most 1800 pixels wide.

## Christian history images

Twenty-three files in `assets/data/christian_history/images/` were PNG or GIF data stored with a `.jpg` name. They were renamed to `.png`, except `fall_rome.gif`, which is GIF data. The history JSON paths were updated to match. Their picture sources are unchanged.
